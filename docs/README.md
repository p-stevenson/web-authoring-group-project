# HOBBYCLUB

Five-page hobby website for a web authoring assignment. Built with HTML and CSS only.

## Current Status

- Home page is working with sticky navigation, hero animation, hobby cards, and the `READ MORE` jump link.
- All four hobby pages are live and share the same layout.
- `motorcycling.html` and `travel.html` are still the strongest visual references.
- `gardening.html` and `hiking.html` now have proper copy, real resource links, and temporary video slots.
- Footer legal links still point to `404.html` in this assignment version.

## Main Files

- `index.html` - home page
- `gardening.html`, `hiking.html`, `travel.html`, `motorcycling.html` - hobby pages
- `style.css` - shared site styles and home page layout
- `sub-template.css` - shared layout for the hobby pages
- `gardening.css`, `hiking.css`, `travel.css`, `motorcycling.css` - page-specific styling
- `docs/PROJECT_PROCESS.md` - project notes

## Editing Notes

1. Change page copy in the relevant HTML file.
2. Keep the existing wrapper classes so the shared CSS still behaves.
3. Use the page-specific CSS file if you need to change colours, fonts, or carousel images.
4. Preview on mobile width as well as desktop.

If you want a good live example, start with `motorcycling.html` or `travel.html`.

## Images

1. Put new files in `images/`.
2. Use simple lowercase names with hyphens, for example `images/hiking-trail.jpg`.
3. Update carousel images in the page CSS rather than changing the carousel HTML.
4. Keep image sizes reasonable so the pages stay quick to load.

## Video

1. Replace the `iframe` `src`, `title`, and supporting text in the page you are editing.
2. Keep the existing wrapper classes.
3. Check embeds on a local server when you can, because `file://` previews can be awkward.

## Upload

1. Upload only the files you changed.
2. Keep the folder structure the same.
3. Refresh the live site and re-check navigation, links, and media.

## Local Preview

Open `index.html` through Live Server or another local server and move through the site from there.
